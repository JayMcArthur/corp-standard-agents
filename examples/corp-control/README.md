# Example Corp Control Repo

This checked-in example models the current official product story:

- `org/` defines the corp baseline and the unknown-workspace onboarding skill
- `repo-groups/platform/` defines shared defaults for sister repos
- `repos/internal-app/` shows repo-only external skills and docs
- `users/alice/` shows the corp-resident person profile path

Read this alongside `scripts/bootstrap_examples.sh` if you want a disposable runtime that exercises the example end to end.

The goal is to build a universal agent context system that lets individuals and teams manage reusable AI skills, workflows, policies, playbooks, and project knowledge from private git-based packs, then apply them safely across any repo without needing to store private agent infrastructure inside the codebase.
I’m envisioning something that starts simple as a personal skill manager, but can grow into a team coordination layer where everyone’s agents understand the same standards, client boundaries, project context, and repeatable processes. A developer can clone or update shared packs, bind them to the projects they work on, and have their agent automatically operate with the right context for that repo while keeping client repos clean and private team knowledge protected.
It should use scripts or solid methods for setup and deploy or as many things as possible to make it repeatable accorssed any machine and any repo

# Changelog

## 0.1.0

- Initial public release candidate of `team-agents`
- Git-backed corp control repo loading
- User override layering and personal source support
- Repo detection by normalized git remotes
- External source pinning with optional fingerprint verification
- Trust-on-first-use records for user-managed sources
- Codex `.agents/` generation with client/privacy safeguards
- `setup`, `sync`, `status`, `doctor`, `init-corp-repo`, and `init-user-overrides` commands
- Checked-in examples, bootstrap scripts, and release/authoring docs

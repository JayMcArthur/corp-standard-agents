# Changelog

## 0.1.0

- Initial public release candidate of `team-agents`
- Git-backed corp control repo loading
- Local user layer and personal source support
- Repo detection by normalized git remotes
- External source pinning with optional fingerprint verification
- Trust-on-first-use records for user-managed sources
- Claude Code, Codex CLI, Cursor, and `AGENTS.md` generation with client/privacy safeguards
- `setup`, `attach`, `sync`, `status`, `context`, `audit`, `registry`, `doctor`, `validate`, `init-corp-repo`, and `init-user-layer` commands
- Checked-in examples, bootstrap scripts, contract specs, and authoring docs
